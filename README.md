# StudySync

A web-based collaborative learning platform for ALU students to form study groups, schedule sessions, and share learning resources.

## Tech Stack
- Frontend: React.js + Material UI
- Backend/Database: Supabase (PostgreSQL)
- Authentication: Supabase Auth
- File Storage: Supabase Storage

## Features
- User Registration and Login
- Create and Join Study Groups
- Schedule Study Sessions
- Upload and Download Resources
- Notifications
- Profile Management

## How to Run Locally

### Prerequisites
- Node.js installed
- A Supabase account

### Steps

1. Clone the repository
   git clone https://github.com/yusufcherish7-hash/studysync.git

2. Navigate into the project folder
   cd studysync

3. Install dependencies
   npm install

4. Create a .env file in the root folder with:
   REACT_APP_SUPABASE_URL=your_supabase_url
   REACT_APP_SUPABASE_KEY=your_supabase_publishable_key

5. Start the app
   npm start

6. Open your browser at http://localhost:3000
